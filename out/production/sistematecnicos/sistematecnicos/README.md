# proyecto_algoritmos
El avance 1 del proyecto presenta la creacion de la clase tecnico y el arreglo donde van a estar
almacenados.

Cada funcion que se cree usando algun algoritmo de busqueda o similar para el manejo de la 
estructura de datos debe ser **COMENTADO** para poder mencionarlo al momento de la exposicion, al igual
de los metodos constructores para poder inferir los atributos de las clases creadas.
